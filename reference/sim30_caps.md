# A `caps` object from simulated data for examples

An object of class
[`caps`](https://astamm.github.io/fdacluster/reference/caps.md) storing
the result of the
[`fdakmeans()`](https://astamm.github.io/fdacluster/reference/fdakmeans.md)
function applied on the data set
[`simulated30`](https://astamm.github.io/fdacluster/reference/simulated30.md)
using the affine warping class and the Pearson metric and searching for
2 clusters.

## Usage

``` r
sim30_caps
```

## Format

An object of class
[`caps`](https://astamm.github.io/fdacluster/reference/caps.md).
