## Clustering methods

- [`fdadist()`](https://astamm.github.io/fdacluster/reference/fdadist.md)
  : Computes the distance matrix for functional data with amplitude and
  phase separation
- [`fdadbscan()`](https://astamm.github.io/fdacluster/reference/fdadbscan.md)
  : Performs density-based clustering for functional data with amplitude
  and phase separation
- [`fdahclust()`](https://astamm.github.io/fdacluster/reference/fdahclust.md)
  : Performs hierarchical clustering for functional data with amplitude
  and phase separation
- [`fdakmeans()`](https://astamm.github.io/fdacluster/reference/fdakmeans.md)
  : Performs k-means clustering for functional data with amplitude and
  phase separation
